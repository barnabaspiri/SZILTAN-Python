# SZILTAN-Python

Kedves Érdeklődők!

Az itt közzétett feladatok a Budapesti Műszaki és Gazdaságtudományi Egyetem Gépészmérnöki karán a Műszaki Mechanikai Tanszék által oktatott Szilárdságtan c. tárgy 2026/27/1 félévben tartott gyakorlati példáinak kidolgozása _Python_ segítségével.

A _Python_ telepítéséhez segítséget lehet találni a következő oldalon: [segédlet](https://www.python.org/downloads/)

Struktúra:
- *01_PYTHON_Bevezeto* mappa: két bevezető anyagot tartalmaz, amely a _Python_ általános használatát mutatja be.
- *02_GYAKORLAT_Feladatok* mappa: a gyakorlati feladatok kidolgozását tartalmazza.
- *03_EXTRA_Feladatok* mappa: egyéb, plusz feladatok kidolgozását tartalmazza.

Minden mappában egy kidolgozott feladat szerepel. A futtatható verziót a `.ipynb` fájlok tartalmazzák. Ezek ún. notebook fájlok, amelyeket *Jupyter Notebook* vagy *Jupyterlab* felületen lehet megnyitni (segédlet ezen csomagok telepítéséhez [itt](https://jupyter.org/install)).

A fájlok futtatásához a következő _Python_ csomagok szükségesek, amelyeket a ```pip``` csomagkezelő segítségével lehet telepíteni (CMD.exe segítségével):
```
pip install numpy
pip install sympy
pip install matplotlib
pip install notebook
pip install jupyterlab
```
